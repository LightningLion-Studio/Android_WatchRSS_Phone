# 手机协助手表登录 B 站

登录只能由手表发起，手机版不提供登录入口。

1. 手机和 Watch S 打开蓝牙，手机端腕上RSS保持前台（已有应用授权和附近设备权限）。
2. 在 Watch S 的腕上RSS进入「B站音频」并打开登录页。
3. 手机收到当前 BLE 连接的 `auth.open` 后打开 B 站登录页，用户完成确认。
4. 手表通过 `auth.poll` 取得账号并写入手表本机存储。

手机登录 Activity 不导出，且必须带当前有效的手表请求会话；无有效会话直接关闭。手机上的刷新二维码只服务于这次手表请求。连接断开或会话超时后，只能从手表重新发起。

登录会话在内存暂存五分钟，断开或关闭服务会清空，旧网络结果不能覆盖新会话。网页登录使用 Android WebView Cookie 存储。release 固定生产后端，使用 `adb install -r` 覆盖安装以保留应用数据；不要在用户手机运行会卸载重装的 connected tests。
